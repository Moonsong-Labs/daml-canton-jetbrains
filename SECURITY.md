# Security Policy

## Supported Versions

The latest released plugin version is supported for security fixes.

## Reporting a Vulnerability

Do not open a public issue for a vulnerability. Email security reports to:

```text
ezequiel@moonsonglabs.com
```

Include:

- Plugin version.
- JetBrains IDE and build number.
- DAML/DPM/Canton versions if runtime behavior is involved.
- Steps to reproduce.
- Logs, stack traces, screenshots, or sample projects when safe to share.

We will acknowledge reports and coordinate remediation before public disclosure.
